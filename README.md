# INALCO · prototipo web

Abre `index.html` en un navegador o usa la extensión Live Server de Visual Studio Code. No requiere instalación ni conexión.

Incluye portada, catálogo, filtros, fichas, carrito con persistencia local, INALBOT con respuestas predefinidas, solicitud de contacto y cita simulada. Los precios, inventario y datos son de demostración. No se procesan pagos, reservas, mensajes ni cuentas reales.

Archivos: `index.html` (estructura), `styles.css` (diseño), `script.js` (interacciones), `assets/referencia-inalco.png` (imagen del mockup aportado como referencia visual). Las fotografías dentro del prototipo se muestran desde regiones de esa imagen; para una entrega comercial deben reemplazarse por fotografías originales autorizadas.
